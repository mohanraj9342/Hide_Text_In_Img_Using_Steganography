How It Works

Simple, secure, and runs entirely in your browser.

01
🖼️

Upload Your Image

Choose any PNG or JPG image to use as the cover. Each pixel secretly stores 3 bits of data in its RGB channels.

→
02
🔐

Optionally Encrypt

Add an extra layer of security with AES-GCM password encryption via the Web Crypto API before embedding.

→
03
⚡

LSB Embedding

The text is converted to binary and embedded into the least significant bit of each color channel — visually imperceptible.

→
04
📥

Download & Share

Download the stego image as a lossless PNG and share it. Only those with StegoCrypt (and the password) can decode it.

LSB Explained

Original pixel byte 11010011 Bit 0 = 1
→
Modified pixel byte 11010010 Bit 0 replaced with secret "0"
→
Color change 211 → 210 Invisible to the naked eye
